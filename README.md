## How to Use

1. **Open the website**: Open `index.html` in any modern web browser
2. **Navigate**: Use the navigation menu to explore different sections
3. **View packages**: Browse through the 5 tour packages
4. **Book packages**: Click "Book Now" on any package to open the booking modal
5. **Search flights**: Use the ticket booking form to search for flights
6. **Contact**: Fill out the contact form or use the provided contact information

## Customization

The website uses a modern color palette that can be easily customized in `styles.css`:
- Primary: `#667eea` (Blue)
- Secondary: `#764ba2` (Purple)
- Accent: `#ffd700` (Gold)

- **Company Information**: Update the company details in the HTML
